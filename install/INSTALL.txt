MODELWRIGHT - INSTALL GUIDE
===========================

Modelwright is an add-in for 64-bit Windows Excel: Microsoft 365, Excel 2024 and Excel 2021.
32-bit Excel, Excel for Mac and Excel for the web are not supported. Windows on Arm is untested.
You do not need administrator rights.

The Modelwright zip contains:
  Modelwright64.xll      the add-in
  install.ps1             installs it for you (Option A)
  uninstall.ps1           removes it
  SHA256SUMS.txt          checksum of the add-in
  LICENSE, THIRD_PARTY_NOTICES.md

There are four ways to install. Pick one:
  A  Install script       recommended; needs PowerShell scripts to be allowed
  B  Windows installer    Modelwright-<version>-x64.msi from the release page; needs installers
     (MSI)                to be allowed; uninstall from Settings > Apps
  C  By hand              no scripts and no installer: Excel's own Add-ins dialog
  D  IT / from source     for locked-down companies, and anyone who must not run downloads


BEFORE YOU START
----------------
1. Check that your Excel is 64-bit. In Excel: File > Account > About Excel. The first line ends
   in "64-bit" (fine) or "32-bit" (not supported: Modelwright cannot load in 32-bit Excel).
   Most computers have 64-bit Excel.
2. Unblock the download. Windows marks files that come from the internet, and Excel refuses to
   load a marked add-in (its "Microsoft Excel Security Notice" offers only "Leave this add-in
   disabled"). Right-click the downloaded Modelwright zip > Properties > General tab > tick
   "Unblock" > OK. Then right-click it > Extract All... > Extract. Files extracted from an
   unblocked zip are clean. (If there is no Unblock box, the file was not marked, which is fine.)
3. Close Excel completely.


WHY WINDOWS WARNS YOU
---------------------
This release is not code-signed (signed builds are planned). So:
- When you run the MSI, Windows SmartScreen may say "Windows protected your PC". Click
  "More info", check the file name, then click "Run anyway".
- Excel refuses the downloaded add-in until it is unblocked (Before you start, step 2). The
  install script and the MSI unblock it for you; by hand, you unblock it yourself.
Unblocking trusts this one file; it does not change any security setting.

If your company requires signed add-ins (Trust Center > Add-ins > "Require Application Add-ins
to be signed by Trusted Publisher"), this unsigned release cannot load there, whatever you do.
Ask IT to trust Modelwright's publisher once a signed build exists, or to build and deploy it
themselves (Option D).


OPTION A - RUN THE INSTALL SCRIPT (recommended)
-----------------------------------------------
1. Close Excel.
2. In the extracted folder, right-click install.ps1 > Run with PowerShell
   (on Windows 11 it may be under "Show more options").
   If that does not work, open PowerShell and paste this line (change the folder if you extracted
   somewhere else):
     powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\Modelwright\install.ps1"
3. The script checks that your Excel is 64-bit, copies the add-in to %APPDATA%\Microsoft\AddIns,
   unblocks it, and adds it to Excel's add-in list. It changes nothing if Excel is open.
4. Start Excel. The Modelwright tab appears on the ribbon.

To preview without changing anything, add -WhatIf to the command. -Verbose shows more detail.

If the script stops, it says why. Its exit codes (for IT and deployment tools):
  0  installed, or already installed
  1  unexpected error
  2  Excel is running: close it completely
  3  could not tell 32-bit from 64-bit Excel (for example EXCEL.EXE was not found): if your Excel
     is 64-bit, add -ExcelBitness 64 to the command
  4  Modelwright64.xll is not next to install.ps1: extract the whole zip
  5  .NET Framework 4.8 is missing
  6  the .xll does not match SHA256SUMS.txt: download the release again
  7  the .xll could not be checked against SHA256SUMS.txt (neither Get-FileHash nor certutil
     worked): verify it by hand (FOR IT, below) or use Option C
  8  your Excel is 32-bit: Modelwright is 64-bit only, and nothing was changed


OPTION B - RUN THE WINDOWS INSTALLER (MSI)
------------------------------------------
Use this if you prefer a normal Windows installer, or scripts are blocked but installers are not.
1. On the release page, download Modelwright-<version>-x64.msi (not the zip).
2. Close Excel.
3. Double-click the .msi. If SmartScreen says "Windows protected your PC", click "More info" >
   "Run anyway" (see "Why Windows warns you"). No administrator password is needed; if Windows
   asks for one, your company blocks installers: use Option A or C.
4. A progress window appears for a few seconds. If Excel is still open it asks you to close it
   (Retry), and it stops with a message on 32-bit Excel.
5. Start Excel. The Modelwright tab appears on the ribbon.
The MSI installs for you only, to %LOCALAPPDATA%\Programs\Modelwright, and registers the add-in
with Excel the same way the script does. A newer MSI upgrades it in place.
To remove it: Settings > Apps > Installed apps > Modelwright > Uninstall (with Excel closed).
For IT: msiexec /i Modelwright-<version>-x64.msi /qn /l*v install.log installs silently (exit
code 0 success, 1603 failure, for example Excel open or 32-bit; the log says why).


OPTION C - ADD IT BY HAND (no scripts, no installer)
----------------------------------------------------
1. Close Excel.
2. Copy Modelwright64.xll to your add-ins folder: paste  %APPDATA%\Microsoft\AddIns  into the
   File Explorer address bar and press Enter.
3. Right-click the copied .xll > Properties > tick "Unblock" if it is there > OK.
4. Start Excel. File > Options > Add-ins. At the bottom, Manage: "Excel Add-ins" > Go...
5. Click Browse..., select the .xll you copied, and click OK.
6. Make sure "Modelwright" is ticked, then click OK.
7. The Modelwright tab appears on the ribbon.


IF YOUR COMPANY BLOCKS IT
-------------------------
- "Leave this add-in disabled": the file is still marked as downloaded. Close Excel, unblock the
  .xll in %APPDATA%\Microsoft\AddIns (step C3) or run install.ps1 again, then start Excel.
  Do not turn the block off in the Trust Center or the registry; that weakens security for every
  add-in. Unblocking this one file is enough.
- "The file format and extension of 'Modelwright64.xll' don't match": your Excel is 32-bit,
  which Modelwright does not support.
- The tab is missing after a crash: File > Options > Add-ins > Manage: "Disabled Items" > Go...,
  select Modelwright > Enable.
- Signed add-ins required, or scripts and add-ins blocked outside approved folders: see "Why
  Windows warns you" above, and ask IT (Option D).
- Scripts blocked: use Option B or C. Installers blocked (Windows asks for an administrator, or
  AppLocker blocks unsigned installers): use Option A or C.


USING IT WITH MACABACUS
-----------------------
Modelwright uses the same keyboard shortcuts as Macabacus. Whichever add-in registered its
shortcuts last gets the key, so run only one of them at a time:
- Turn Macabacus off: File > Options > Add-ins > Manage: "COM Add-ins" > Go... > untick
  Macabacus > OK.
- Turn Modelwright off: File > Options > Add-ins > Manage: "Excel Add-ins" > Go... > untick
  Modelwright > OK.
- For this session only: click Modelwright > Re-register shortcuts (Modelwright wins), or
  Macabacus's Override (Macabacus wins).


REMOVE IT
---------
Close Excel completely first (check Task Manager for a background EXCEL.EXE): Excel rewrites its
add-in list when it closes, which would undo the removal. Remove it the way you installed it:
- Installed with the MSI: Settings > Apps > Installed apps > Modelwright > Uninstall.
- Installed with the script: right-click uninstall.ps1 > Run with PowerShell, or paste:
    powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\Modelwright\uninstall.ps1" -RemoveFile
  (-RemoveFile also deletes the .xll from %APPDATA%\Microsoft\AddIns.)
- Installed by hand: File > Options > Add-ins > Manage: "Excel Add-ins" > Go... > untick
  Modelwright > OK, then close Excel and delete the .xll from %APPDATA%\Microsoft\AddIns.
If Excel ever says "Cannot find add-in 'Modelwright64.xll'. Delete from list?", answer Yes: it is
a leftover entry for a file that was deleted.

Your settings are kept in %APPDATA%\Modelwright (settings.json) and the log in
%LOCALAPPDATA%\Modelwright. Uninstalling never deletes them; delete those folders yourself if you
want them gone.


OPTION D - FOR IT, AND BUILDING FROM SOURCE
-------------------------------------------
Verify the files. Compare each file's SHA-256 with SHA256SUMS.txt (and with the digest GitHub
shows next to each release asset):
  Get-FileHash .\Modelwright64.xll -Algorithm SHA256
  certutil -hashfile Modelwright64.xll SHA256        (where PowerShell is blocked)
Check which workflow run and commit built a file (GitHub CLI):
  gh attestation verify .\Modelwright64.xll -R jwriccardi/modelwright
Show a code signature, if the release is signed:
  Get-AuthenticodeSignature .\Modelwright64.xll

Deploy. Per-user registration is one registry value, written with Excel closed:
  HKCU\Software\Microsoft\Office\16.0\Excel\Options, the next free OPEN, OPEN1, OPEN2, ... value
  (no gaps), type REG_SZ, data:  /R "C:\path\to\Modelwright64.xll"
The file can live in any local folder (not a network share; Program Files is fine for a
per-machine copy). Group Policy Preferences or Intune can set the value; install.ps1 does exactly
this and runs in Constrained Language mode; the per-user MSI does it too and installs silently
(Option B).

Build from source, for people who must not run downloaded binaries. Needs Windows 10 or 11 and
internet access to nuget.org (or your company's NuGet proxy). Visual Studio is not needed.
1. Install the .NET SDK 10.0.100 or a later 10.0 feature band (the repository's global.json pins
   10.0.100 with rollForward latestFeature). It can be installed without admin rights with
   dotnet-install.ps1: https://learn.microsoft.com/dotnet/core/tools/dotnet-install-script
   Running the tests also needs the .NET 8 runtime.
2. Get the source of the release tag (for example v0.1.0) from
   https://github.com/jwriccardi/modelwright (Code > Download ZIP, or git clone).
3. In the source folder:
     dotnet build Modelwright.sln -c Release
4. The add-in is written to:
     src\Modelwright.AddIn\bin\Release\net48\publish\Modelwright64.xll
5. Install it with Option A (run install.ps1 -SourceFolder <that publish folder>) or Option C.
   To build the MSI as well, see CONTRIBUTING.md in the source.
6. Verify: Get-FileHash <file> -Algorithm SHA256. The build is not yet bit-for-bit reproducible
   (it embeds the build date), so a rebuilt file's hash will differ from the release's; use the
   attestation above to tie a release file to its commit.
